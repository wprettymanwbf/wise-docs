# Images Directory

This directory contains shared images and assets used throughout the documentation.

## Organization

* Store shared assets that are used across multiple documentation sections here
* For section-specific images, create an `images/` folder within that section
* Use descriptive filenames for all images

## File Formats

* **PNG** - Screenshots, diagrams, and UI elements
* **JPEG** - Photographs
* **GIF/MP4** - Animations and demos

## Git LFS

All binary image files are tracked using Git LFS. Ensure you have Git LFS installed and configured before adding images.

## Best Practices

* Optimize images before committing
* Use descriptive alt text in documentation
* Keep file sizes reasonable
* Remove unused images regularly
