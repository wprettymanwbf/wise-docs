## Contributing

All team members are encouraged to contribute blog posts. To submit a post:

1. Create a new folder under `blogs/YYYY/MM/DD/` with your post date
2. Write your post in Markdown format
3. Include the required frontmatter (see template below)
4. Submit a pull request
