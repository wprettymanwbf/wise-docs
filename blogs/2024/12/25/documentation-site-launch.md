# Introducing WBF's Internal Documentation Site

December 25, 2024 by the WBF Documentation Team

We're excited to announce the launch of WBF's new internal documentation and knowledge base! This centralized hub will serve as the go-to resource for all company documentation, guides, and knowledge sharing.

## What's New

Our new documentation site includes:

* **Comprehensive Documentation** - All company documentation in one place
* **Easy Navigation** - Intuitive structure with clear categories
* **Search Functionality** - Quickly find what you need
* **Collaborative** - All team members can contribute

## Main Sections

### Documentation

The main documentation section covers:
* Getting started guides for new team members
* Development guidelines and best practices
* Operational procedures
* Security policies

### API Reference

Complete API documentation with:
* Endpoint references
* Authentication guides
* Usage examples
* Best practices

### Learning Resources

Training and educational materials including:
* Onboarding materials
* Technical tutorials
* Professional development resources

### Blog & Announcements

Stay up-to-date with:
* Company announcements
* Technical insights
* Team updates

## How to Use the Site

1. **Browse** - Navigate through the sections using the menu
2. **Search** - Use the search function to find specific topics
3. **Contribute** - Add or update documentation as needed
4. **Stay Updated** - Check the blog for latest announcements

## Contributing

We encourage all team members to contribute! Whether it's:
* Fixing a typo
* Adding a new guide
* Sharing knowledge
* Improving existing documentation

Every contribution helps make our documentation better.

## Getting Started

Check out the [Getting Started Guide](/docs/getting-started/overview.md) to begin exploring the documentation, or visit the [README](https://github.com/wprettymanwbf/wise-docs) for information on how to contribute.

## Feedback

We want to hear from you! If you have suggestions, find issues, or want to request new documentation, please:
* Open an issue in the repository
* Contact the documentation team
* Submit a pull request
